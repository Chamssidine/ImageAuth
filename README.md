# ImageAuth

A Rest API built with ASP.NET for image authentication.

## Overview

ImageAuth is a robust REST API application developed using ASP.NET, providing secure image authentication capabilities.

## Technology Stack

- **C#** (98%) - Primary language
- **ASP.NET** - Web framework
- **Solidity** (1.5%) - Smart contract functionality
- **Docker** (0.5%) - Containerization

## Features

- RESTful API endpoints
- Image authentication and validation
- Built with modern ASP.NET technologies

## Getting Started

### Prerequisites

- .NET SDK (version compatible with the project)
- Docker (optional, for containerized deployment)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Chamssidine/ImageAuth.git
   cd ImageAuth
   ```

2. Restore dependencies:
   ```bash
   dotnet restore
   ```

3. Build the project:
   ```bash
   dotnet build
   ```

4. Run the application:
   ```bash
   dotnet run
   ```

## Docker Usage

Build and run with Docker:

```bash
docker build -t imageauth .
docker run -p 5000:5000 imageauth
```
